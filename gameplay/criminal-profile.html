Criminal Profile

A reputation for each character: professional, or needlessly violent, with consequences.

Criminal Profile tracks how Jason and Lucia go about their work. It resembles the honor system in Red Dead Redemption 2, but Rockstar adds that it does not turn them into upstanding citizens.

The difference the studio names: crime that stays businesslike, set against violence there was no need for. The world responds to that reputation.
