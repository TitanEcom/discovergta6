How GTA 6 preload works on November 12

In two days you can start downloading GTA 6. This is what to check now so the install is done long before November 19.

November 10, 2026 · 2 min read · By DiscoverGTA6

When it starts

Rockstar has confirmed that preload begins on Thursday, November 12. Several guides say it opens at local midnight in your store region, but Rockstar's announcement gives a date, not a time. If it does not show up at midnight, check again in the morning.

Who can preload

  • Digital pre-orders on PlayStation Store or Microsoft Store download automatically if auto-downloads are on.
  • Boxed copies contain a download code, not a disc. Redeem the code and the preload starts the same way.

Make room now

Rockstar has not published a file size. An unofficial PS Store reading puts it near 210 GB, and GTA V Enhanced already takes about 87 GB. Plan for a lot of space:

  • The original PS5 has about 667 GB usable, the PS5 Slim and Pro have more.
  • The 512 GB Xbox Series S fills up fast, so clear space first.
  • Use an internal or supported expansion SSD, not slow external storage.

When you can play

The game unlocks on November 19. An exact time has not been confirmed. Leave the console in rest mode overnight so day-one patches download too.

Last check

If you want the Vintage Vice City Pack, your digital purchase has to be in before November 20. See the latest on our preload page.

Sources: Forbes: GTA VI preload window, GTA Intel: preload facts, Space4Games: preload times. Spotted a mistake? Let us know.

On Thursday, November 12, 2026. Rockstar has not given an exact time.

Yes. The box contains a download code, so you redeem it and preload the same way.
